
Hospital Emergency Queue Management System

About the Project

The Hospital Emergency Queue Management System is a C/C++ project designed to manage patients waiting for emergency treatment in a hospital. It aims to organize the patient queue and help prioritize patients according to their emergency levels.

Objectives

- Manage patients in a hospital emergency queue.
- Organize patients according to their emergency priority.
- Improve the organization of patient waiting queues.
- Practice queue data structures and programming concepts.

Features

- Patient queue management.
- Emergency priority handling (depending on implementation).
- Organized patient records.
- Simple and easy-to-understand project structure.

Technology Used

- Programming Language: C/C++
- Concepts: Queue and Data Structures

Project Files

- "main.c" — Main program file.
- Project PDF files — Supporting project documentation.

How to Run

1. Download or clone this repository.
2. Open the source file in a suitable C/C++ compiler.
3. Compile and run the program.
